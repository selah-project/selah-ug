# تانائ — ئۇيغۇرچە تەرجىمە (selah-ug)

بۇ ئامبار — ئىبرانىي تانائنىڭ ئۇيغۇرچە تەرجىمىسى. ھەر ئايەت ئۆز
ھۆججىتىدە تۇرىدۇ، ھەر سۆز ئۆز ئىبرانىي ئەسلىسىگە باغلانغان.

**يېزىق: ئۇيغۇر ئەرەب يېزىقى (UEY).** بۇ — بۈگۈن ئوقۇرمەنلەر
ھەقىقىي ئوقۇيدىغان يېزىق. لاتىن (ULY) ۋە كىرىل (USY) يېزىقلىرى
ئارخىپ خاتىرىسى بولۇپ، ئەسلىنىڭ ئورنىنى باسمايدۇ.

## ھۆججەت شەكلى

```
<كىتاب>/<باب>/<ئايەت>.json
```

ھەر ھۆججەت:

```json
{
  "translation": "ئايەتنىڭ ئېقىمى",
  "tokens": [{"surface": "ئىبرانىيچە سۆز", "gloss": "ئۇيغۇرچە مەنىسى"}]
}
```

`surface` — ئىبرانىي خاتىرىسى. ئۇ بىزنىڭ يېزىدىغىنىمىز ئەمەس؛ ئۇ
ئەسلىدىن كېلىدۇ ۋە ئۆزگەرتىلمەيدۇ.

## ⟨ ⟩ بەلگىلىرى نېمە؟

ئىككى خىل ئىش ئۈچۈن ئىشلىتىلىدۇ، ۋە ئۇلارنى ئايرىش مۇھىم:

- **⟨את⟩** — ئىبرانىيچىنىڭ بىۋاسىتە ئوبيېكت بەلگىسى. ئۇيغۇرچىدا
  ئىسمى يوق، شۇڭا ئىبرانىيچىدە قانداق تۇرسا شۇنداق تۇرىدۇ.
  ئوقۇرمەن ئۇنى كۆرىدۇ — يوشۇرۇلمايدۇ.
- **⟨سۆز⟩** — ئىبرانىيچە يازمىغان، ئەمما ئۇيغۇرچە گرامماتىكىسى
  تەلەپ قىلغان سۆز. ئۇ قوشۇلغان، شۇڭا بەلگە ئىچىدە تۇرىدۇ.

## ئىسىملار

| ئىبرانىيچە | بۇ يەردە |
|---|---|
| יהוה | **ياھۋەھ** |
| אלהים | **ئېلوھىم** |
| אדני | **ئادوناي** |
| שדי | **شادداي** |
| אל | **ئەل** |
| יה | **ياھ** |
| שאול | **شېئول** |

خۇدانىڭ ئىسمى تەرجىمە قىلىنمايدۇ — تاۋۇشلىنىدۇ. **خۇدا**، **اﷲ**،
**تەڭرى**، **پەرۋەردىگار** — ئەنئەنە سۆزلىرى، بۇ يەردە ئىسىم
ئورنىدا تۇرمايدۇ.

**شېئول** — «دوزاخ» ئەمەس، «جەھەننەم» ئەمەس.
